# Алим Нагоев | Фронтенд-разработчик

👨‍💻 **Опытный фронтенд-разработчик**, специализируюсь на создании высококачественных веб-приложений с использованием **JavaScript**, **TypeScript**, **React** и **Next.js**. * **Стилизация:** Tailwind CSS

* **Работа с API:** Axios
* **Утилиты:** date-fns, uuid, lodash
